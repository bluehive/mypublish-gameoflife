## 3. howtocode / 本書に既にあるベースライン（抽出）

intro 0.6 + ch02 2.1 より、本文と整合する要素:

**データ側**
1. 記述（Description）
2. 解釈（Interpretation）
3. データの例（Data Examples）
4. データ用テンプレート

**関数側**
1. 署名（signature / `: …` またはコメント）
2. 目的（purpose）一文
3. stub（骨だけの define）
4. 例 = `check-expect`
5. 関数テンプレート（`...` プレースホルダ）
6. 本体を埋める
7. Run → 見直し

本書の題材ルート（意図であって目次ではない）:
- 式・define・cond（構文）
- リスト再帰テンプレ
- グリッド（ListOfPosn）
- ライフ規則
- 表示 / 目視 + check-expect

## 4. 追加仕様（実装）

### 挿入位置


※ 0.5 の章予告・EPUB 自動目次とは役割を分ける一文を冒頭に置く。

### フローに載せるノード（必須）
- 題材: ライフゲーム（車両）
- データ: 記述 → 解釈 → **例** → （データ）テンプレ
- 関数: 署名 → 目的 → stub → **例(check-expect)** → **テンプレ** → 本体 → Run/見直し
- 失敗時: 例・テンプレへ戻るループ
- 積み上げ: 式 → リスト再帰 → 盤 → 規則 → 表示（章 TOC の再掲にしない。短い横または縦の「積み木」）

### スタイル
- ```text フェンス内 ASCII
- 幅おおよそ 70 桁以内（Zenn/EPUB 折り返し耐性）
- Scratch 言及なし（PR #22 方針と整合）

### 非目標
- 章ごとの詳細 TOC の再掲
- 新概念の長文説明（図＋短い前後文のみ）
- code/ 変更
