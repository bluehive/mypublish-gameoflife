##### 【三角ロジック】

| 要素 | 内容 |
|------|------|
| **データ** | 遠隔で「絵を描け」と伝えたいとき、文字列をそのまま実行すると危険である。許可した命令だけを、入れ子のリストで表すと、描画・まとめ・名前・新しい関数まで書ける。 |
| **ワラント** | プログラムをデータと同じ形で扱いたいなら、いちばん単純な入れ子はリストである。 |
| **主張** | 丸括弧の連なりは気まぐれな発明というより、その条件を削ぎ落とした先に現れやすい形——発見——である。 |

#### J.1 思考実験：命令を「安全なデータ」にする

画面に線を引くプログラムがある、とします。手元なら `draw-line` を呼べばよい。困りごとを一つ足します。**遠くから送られてきた描画の指示を、こちらで実行したい。**

最初の思いつきは、「文面を、そのままプログラムとして走らせる」ことです。これは強すぎます。相手が書いた文字が、描画以外のことまでできてしまう。だから **許可した命令だけ** を、データの形で受け取ります。

命令カードのイメージです。

```text
名前: draw-line
材料: 点A, 点B, "blue"
```

キー名は毎回同じなので、省略できます。**先頭がすること、残りが材料**、という規則にします。思考実験では角括弧のリストで書きます（本編の `cond` の枝や、BSL のリストとは別物だと覚えてください）。

```text
["draw-line", 点A, 点B, "blue"]
```

次に、材料の中にも命令を入れたくなります。

```text
["rotate", ["draw-line", 点A, 点B, "blue"], 90]
```

規則は二行で足ります。

1. リストでなければ、それはすでに値（点や色や数）である。  
2. リストなら、先頭の関数に、残りの材料を（内側から）渡す。

序章 0.4 の「内側から外側へ値に落とす」と同じ向きです。ここで出てくる再帰は、第2章のリスト処理と **形は似る** が、目的は「式を値にする」ことです。

さらに三つだけ足すと、命令の集まりは言語に近づきます。

- `do` … 複数の命令を順に行う  
- `def` … 名前を値（または関数）に結びつける  
- `fn` … 「今は計算せず、あとで使う機械」を作る  

`def` と `fn` は、本編の `define` と、付録Iの「手続きオブジェクト」に対応します。`do` は本線 BSL には出てきません。ここでは「まとめ役」だとだけ覚えてください。

安全な命令フォーマットを作ろうとしただけなのに、気づけば小さなプログラミング言語を書いています。

#### J.2 コードがデータであること

この配列言語には、ふつうの言語にはない手触りがあります。

- **特別扱いが少ない。** `const` のようなキーワードは、ユーザーが書き換えられません。こちらでは `def` も `draw-line` も同じリストです。言語作者と利用者の差が、構文の壁としては薄い。  
- **コードを書き換えるコードが短い。** たとえば `unless` を「条件を否定した `if`」に直す作業は、リストの先頭と中身を組み替えるだけで済む（いわゆるマクロ。本編では扱いません）。  
- **構造で編集できる。** 文字ではなく「この枝」を広げたり、一段上げたりできる（Paredit など。発展）。

要するに、**プログラムそのものが、いつものデータ操作の対象**になります。

#### J.3 種明かし：それは Lisp の見た目である

角括弧を丸括弧に変え、カンマを消し、文字列の名前を記号（引用符のない名前）にすると、本書の式と同じ家族になります。

```text
["do",
  ["def", "draw-triangle",
    ["fn", ["left", "top", "right", "color"],
      ["do",
        ["draw-line", "left", "top", "color"],
        ["draw-line", "top", "right", "color"],
        ["draw-line", "left", "right", "color"]]]],
  ["draw-triangle", 点L, 点T, 点R, "blue"]]
```

```racket
; 見た目を整えたもの（イメージ。本編 BSL の練習問題ではない）
(define (draw-triangle left top right color)
  (draw-line left top color)
  (draw-line top right color)
  (draw-line left right color))
```

原記事は Clojure で同じ対応を示しています。規則は共通です。`(draw-line left top color)` は、「`left` `top` `color` を値にしてから、`draw-line` を走らせる」という意味です。

#### J.4 結論：削ぎ落とすとリストに着く

「プログラムをデータとして扱いたい。そのための、いちばん単純な入れ子は何か。」

XML でも JSON でも書けます。無駄を削ると、残るのは入れ子のリストです。Lisp のカッコは、その答えの見た目です。気まぐれに増えた飾りというより、条件を最適化した先に現れやすい形——だから **発明というより発見**——だ、と原記事は述べます。より良い表面文法があり得るかも、とも残しています。本書が Racket（BSL）を選ぶ理由の一つは、その発見に、入門用の小さな言語で触れられることです。
